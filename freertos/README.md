# FreeRTOS 主控工程（开发中）

此目录是新工程，与原有 Zephyr 源码分开。`app/` 和 `include/` 是不依赖 RTOS 和硬件的业务内核；`tp_tick` 不等待外设，调用方必须周期调度，并在同一任务中串行执行启动、停止和状态机更新。硬件接口必须提供真实的泵脉冲完成状态、外部反应池温度及可靠的安全关断，不能用时间推算泵完成或 MCU 内部温度代替。配方内存须在运行期间保持有效且不可修改。

当前实现：可取消流程框架、泵动作及超时、阀动作、持续温控、采样平均、光学计算和故障安全输出，以及双槽配置存储和 Modbus RTU 帧处理的通用代码。这里的浓度计算是可配置的软件模型，未经过化学方法或仪器标定验证。提供用于学习的示例配方；真实仪器的温度、泵量、阀门、通道和反应参数须按硬件和化学方法确定。

已提供 F407 的参考外设适配、业务装配及可选业务入口；默认构建是心跳镜像，业务入口需要独立板级配置才能启动。已提供升级、从控及 Zephyr 采集切片的参考实现，实际硬件及端到端联调仍待完成；详情见 `docs/STATUS.md` 和 `docs/MODBUS.md`。根目录 CMake 用于主机侧业务库和检查，`firmware/` 用于交叉构建目标固件。参考驱动、实际硬件及安全联锁尚未实机验证。

学生可先阅读 [快速上手](docs/LEARNING.md)，在电脑上运行模拟流程和故障场景。

## 主机模拟

在本目录用 CMake 构建主机目标后，运行 `build/tp_simulator`（Windows 为 `build/tp_simulator.exe`）观察受控模式下的阀门、泵、加热、采样和浓度计算；追加 `interlock` 或 `sensor` 参数可注入对应故障，`stop-rinse` 可在清洗泵运行时发送停机命令。示例依次模拟取样、空白和浊度读取、加试剂、加热保温、反应读数、计算、清洗和排液；阀位与泵参数只是演示值。程序以 Modbus RTU 帧发送启动和逐步命令，输出步骤、模拟温度和最终状态，并在运行结束时检查安全输出。运行 `build/tp_simulator recover` 或 `build/tp_simulator recover-sensor` 可分别演示互锁及 ADC 故障恢复，后者依次模拟排除故障、恢复 ADC 配置、清故障并重新启动。运行 `build/tp_simulator calibration` 可演示模拟两点自动标定、应用和标液核查。 运行 `build/tp_simulator journal` 可将一次完整模拟测量的完成事件写入内存日志，重新打开后通过 Modbus 查询并核对浓度；该演示在同一线程直接处理日志，不代表 FreeRTOS 后台队列或实际存储器已联调。`ctest --test-dir build --output-on-failure` 包含上述模拟场景。模拟时间不依赖真实时钟。

示例的配方、温度模型、光信号和标定系数均为人为构造，仅用于学习软件调用关系，不能作为仪器配方、硬件性能或测量准确度的依据。它不模拟 FreeRTOS 调度、串口时序或真实器件通信。

### 简易图形上位机

安装 Python、Tkinter 和 pyserial，在 `freertos` 目录运行 `python tools/tp_gui.py`。填写串口、波特率及从站地址后点击“读取状态”，可发送启动、停止、清故障、下一步、自检和 ADC 恢复命令，也可设置运行模式及保存配置，启动自动两点标定、应用标定结果和启动标液核查，并读取各自状态；还可读取最新事件或按序号查询历史事件，查看完成事件中的有效浓度。自动标定完成后须先应用结果，再保存配置并确认保存成功；停止命令可取消正在执行的标定或核查。每日模式可先使用“用电脑时间校时”，再读取时钟确认回读成功；请确保电脑时钟正确。时钟显示 UTC 时间。点击“读取模式”查看设备当前模式及参数，输入框初始值只是示例。模式的“每日分钟”是当地 00:00 起的分钟数，UTC 偏移单位为分钟。设置模式只改变内存；保存命令入队后须再次读取状态确认保存成功。点击“读取参数”可查看并整组修改标定、PID、温度上限、周期及从站地址；写入后仍需保存并确认。窗口显示读取时的快照，写入会覆盖整组参数，避免其他上位机同时修改；从站地址保存并重启后生效。

更改串口、波特率或地址后，界面要求重新读取；通信期间更改连接会丢弃旧设备的读取结果，已发送命令的结果仍标明原目标。界面手动刷新，状态与温度分两次读取，显示时间可能不同；通信失败或命令超时后应重新读取确认设备状态。串口操作在后台串行执行，通信中其他按钮暂不可用，因此停止按钮不是紧急停止装置。图形界面依赖 PC 的 Python/Tkinter 和串口设备，未经过真实设备联调。
