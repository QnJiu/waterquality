# FreeRTOS 主控工程（开发中）

此目录是新工程，与原有 Zephyr 源码分开。`app/` 和 `include/` 是不依赖 RTOS 和硬件的业务内核；`tp_tick` 不等待外设，调用方必须周期调度，并在同一任务中串行执行启动、停止和状态机更新。硬件接口必须提供真实的泵脉冲完成状态、外部反应池温度及可靠的安全关断，不能用时间推算泵完成或 MCU 内部温度代替。配方内存须在运行期间保持有效且不可修改。

当前实现：可取消流程框架、泵动作及超时、阀动作、持续温控、采样平均、光学计算和故障安全输出，以及双槽配置存储和 Modbus RTU 帧处理的通用代码。这里的浓度计算是可配置的软件模型，未经过化学方法或仪器标定验证。温度、泵量、阀门、通道和反应过程参数尚未确定，不提供可直接运行的化学配方。

尚未实现：STM32 LL 板级、完整的 FreeRTOS 固件构建、STM32 UART/SPI/I2C 对接、真实 RTC、完整运行模式、升级、从控及 Zephyr 迁移。已有 ADS1220 通用驱动、Modbus 寄存器服务、调度和 MB85RC16 通用存储适配，尚未在目标硬件运行；详情见 `docs/STATUS.md` 和 `docs/MODBUS.md`。当前 CMake 仅用于主机侧业务库和检查，不能构建或烧录为固件。实际硬件及安全联锁需后续确定并验证。
