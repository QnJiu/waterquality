# Modbus RTU 寄存器（软件接口初版）

地址均为零起始 PDU 地址，寄存器为 16 位，FC03 读取，FC06/FC16 写入。多寄存器数值高字在前；浓度为 IEEE 754 32 位浮点。此协议是新工程独立定义，尚未和旧工程寄存器表兼容，未接 STM32 UART/RS485；寄存器访问须通过控制任务串行处理。

| 地址 | 意义 |
|---|---|
| 0 | 命令：1 启动、2 停止、3 清故障、4 请求保存配置、5 执行下一步；读取为 0 |
| 1 | 模式：0 受控、1 周期、2 每日定时 |
| 2–3 | 周期秒数，无符号 32 位；周期模式须大于 0 且不超过 2147483 秒 |
| 4 | 每日触发时间，从本地 00:00 开始的分钟数，0–1439 |
| 5 | 固定 UTC 偏移分钟，有符号 16 位，−720 至 +840 |
| 10 | 运行状态：0 空闲、1 运行、2 完成、3 失败 |
| 11 | 故障码，枚举见 `tp_core.h` |
| 12 | 当前配方步骤索引，从 0 开始 |
| 13 | 最近一次启动请求结果，枚举见 `tp_core.h` |
| 14–15 | 最近浓度结果 mg/L |
| 16 | 结果有效标记：完成且完成浓度计算时为 1，其余为 0 |
| 17 | 保存状态：0 不可用、1 已附加配置或待保存、2 保存中、3 成功、4 失败 |
| 18 | 逐步受控等待下一步：1 等待、0 未等待 |
| 20–21 | 标定斜率 slope |
| 22–23 | 标定截距 intercept |
| 24–25 | 浊度系数 turbidity_factor |
| 26–27 | 最小信号 min_signal |
| 28–29 | 最大浓度 max_concentration |
| 30–31 | PID 比例系数 kp |
| 32–33 | PID 积分系数 ki |
| 34–35 | PID 微分系数 kd |
| 36–37 | 温控死区 deadband_c |
| 38–39 | 输出上限 output_max |
| 40–41 | 积分上限 integral_max |
| 42–43 | 温度上限 max_temperature_c |
| 44–45 | 保存的周期秒数，32 位无符号整数 |
| 46 | 保存的 Modbus 从站地址，1–247 |

修改模式配置时必须用 FC16 一次写入地址 1–5，运行中拒绝变更。启动、停止和清故障命令必须单独写入地址 0。受控模式的启动命令执行配方第一步，之后每次以命令 5 执行一步（包括最后的结束步骤）；只有地址 18 为 1 时接受下一步命令。等待期间仍检查互锁并持续调温，30 秒内未继续则报超时故障并安全停机；停机命令随时有效。周期和每日定时模式自动执行完整配方。20–43 是 IEEE 754 32 位浮点，高字在前；20–46 必须用单次 FC16 完整写入并整体校验，运行或保存中拒绝修改。写入仅更新内存，命令 4 将配置提交到后台保存队列；命令成功只代表请求入队，须查询地址 17 确认保存结果，保存中拒绝启动。板级初始化可调用 `tp_runtime_bootstrap_storage` 加载配置并附加存储；STM32 I2C 和板级启动调用尚未接入。

地址 44–45 与地址 2–3 的周期同步；修改周期后从当前时间重新计时，需通过命令 4 保存。附加配置后周期必须在 1–2147483 秒范围内。运行模式、每日时间和 UTC 偏移尚未持久化；写入保存的从站地址不会更新运行中的串口上下文。板级尚未接入配置初始化调用或通信地址切换。

寄存器服务必须与状态机在同一任务执行。通信任务应通过请求队列交给控制任务处理，停止请求使用独立优先队列；不要直接从不同串口任务并发调用这些函数。读取多个寄存器时必须保持快照一致。实际停止响应还依赖任务调度、驱动和硬件，尚未测量。
