# ESP32 采集主控状态（教学示例）

本示例使用 MicroPython，通过 RS485 读取 F407 Modbus 地址 10–16，并每秒在 ESP32 串口控制台打印 JSON。字段包括运行状态、故障码、步骤、启动结果和浓度；当结果无效时浓度为 `null`。寄存器说明见 `docs/MODBUS.md`。

1. 将 `main.py`、`modbus_status.py` 和 `config.example.py` 复制到 ESP32，后者改名为 `config.py`，配置引脚和 F407 从站地址。
2. ESP32 的 TX/RX 经 3.3 V RS485 收发器连接 F407 的 USART3 RS485 总线；DE 与 /RE 同接 `RS485_DE`，高电平发送，低电平接收。按收发器接线连接 A、B 和信号地。该示例要求总线上只有这个 Modbus 主站。
3. F407 需要启用并配置业务入口和 USART3，通信参数为 115200 8N1。观察 ESP32 控制台输出；通信超时或 CRC 错误时输出错误，不把旧浓度作为新数据。

这是云端上报的数据采集部分，目前仅打印状态，没有连接 MQTT 或阿里云。ESP32、RS485 接线及真实串口时序尚未实测，实际引脚和电气连接以板卡和收发器为准。
